# 🛒 E-commerce Sales Analysis Project

## 📌 Project Overview
This project focuses on analyzing an E-commerce sales dataset using Microsoft Excel. The objective is to clean, organize, analyze, and visualize sales data to generate meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives
- Perform data entry and organize datasets using Excel tables.
- Clean customer, product, store, and sales data.
- Handle missing values and inconsistent formatting.
- Apply Excel formulas for data transformation and calculations.
- Perform descriptive statistical analysis.
- Create Pivot Tables to identify business trends.
- Develop an interactive E-commerce Sales Dashboard.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Formulas

- Pivot Charts

## 📂 Project Structure

The workbook contains the following sheets:

| Sheet Name | Description |
|---|---|
| Raw_Customer_Dim | Original customer dataset |
| Clean_Customer_Dim | Cleaned customer information |
| Raw_Product_Dim | Original product dataset |
| Clean_Product_Dim | Cleaned product information |
| Raw_Store_Dim | Original store dataset |
| Clean_Store_Dim | Cleaned store information |
| Raw_Sales_Fact | Original sales transactions |
| Clean_Sales_Fact | Cleaned sales transactions |
| Descriptive_Analysis | Statistical analysis of sales |
| Pivot_Table | Sales summaries and business insights |
| Ecommerce_Dashboard | Visual sales dashboard |

## 🧹 Data Cleaning
The following activities were performed:
- Standardized customer names and text formatting.
- Handled missing customer loyalty levels.
- Identified and standardized product information.
- Handled missing product costs and stock values.
- Created cleaned sales columns for quantity, unit price, and discount.
- Organized raw and cleaned datasets separately.

## 📈 Key Analysis & Insights

**1. Customer Loyalty Analysis**
- Platinum is the largest loyalty segment with 149 customers.
- Female customers account for 262 records, compared with 238 male customers.

**2. Year-wise Sales Analysis**
- 2024 recorded the highest sales of approximately $1.09 million.
- 2025 recorded approximately $856,670.
- 2023 recorded approximately $223,813.

**3. Regional Sales Analysis**
- The North region has the highest average sales value among the four regions.
- The South region also demonstrates strong average sales performance.

**4. Product Category Analysis**
- Sports recorded the highest order count with 498 orders.
- Electronics followed with 454 orders.
- Beauty recorded 304 orders.

**5. Monthly Sales Analysis**
- November 2024 recorded the highest average sales value.
- May showed relatively lower average sales values.
